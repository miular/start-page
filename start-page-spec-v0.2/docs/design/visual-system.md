# Visual System

## Goal

Quiet, precise, modern, lightweight, premium without being flashy, comfortable for daily use.

## Mental model

```text
minimal Apple-inspired composition
+
browser utility
+
restrained Liquid Glass
```

Do not clone Apple's UI.

## Composition

Dominant interaction:
Search

Supporting:
Clock/date

Secondary navigation:
Bookmarks

Ambient:
Quote

Secondary control:
Settings

## Density

Use generous whitespace and controlled information density.

## Borders

Use for:
- separation
- focus/state
- subtle material definition

Do not border everything.

## Shadows

Use small soft elevation. Glass already provides depth.

## Icons

Use a consistent icon system with predictable optical size and accessible labels where needed.

## States

Use subtle but observable state transitions. Avoid large scale transforms and layout shifts.
