# Responsive Specification

## Philosophy

Use content-driven responsiveness rather than many device-specific breakpoints.

## Desktop

Provide:
- generous whitespace
- constrained search width
- compact bookmark row/grid
- low-attention settings control

## Tablet

Reduce horizontal gaps and search width while preserving hierarchy.

## Mobile

Priority:
1. Search
2. Clock/date
3. Bookmarks
4. Quote
5. Settings

Controls must remain comfortably tappable.

## Layout stability

Avoid shifts caused by:
- favicon loading
- font loading
- quote changes
- search state changes

Reserve space where appropriate.

## Orientation

Portrait and landscape should remain usable without separate application layouts.
